# AURI Pressure Takeover Web

This repository contains the public static build of the AURI vehicle HMI and
Demo console. It does not contain Agent credentials, LLM API keys, or backend
environment variables.

Public pages:

- `apps/vehicle-hmi/`
- `apps/demo-console/`
- `apps/web-portal/`

The browser stores the Agent API URL and Team Token in local storage after the
user enters them. Do not commit credentials to this repository.
